## Decisions made

- D87. A template imported after the log filled the form. Amends D80 and D82.
- D82 gains a dated note: the gain row is "USRP gain", and the three names take the
  catalogue's spelling.

## Changes from the plan

- The checklist line "Filled in from the recorder's log" is now worked out from the
  form each time (`still_filled()`), in place of the list stored at the scan. The plan
  asked only that the line stop naming values a template replaced. The same function
  also drops a value the user typed over, which 1.1.0 kept naming.
