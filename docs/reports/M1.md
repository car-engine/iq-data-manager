## Untested or not testable here

- **UNC paths.** `sqlite_uri()` is checked as text only (`file:////nas/recordings/...`).
  Agents may not touch network paths. The user can test it on a scratch database (O21).
- **SMB locking.** The retry logic is tested with two local connections only (O21).

## Issues found in self-review

1. **The spec's file layout was out of date.** Fixed in `e0672c2`.
2. **`finish_transfer` replaces `notes`.** New notes overwrite earlier text. Milestone 6
   will probably need to add to the text instead. Left unchanged; recorded as O12.
3. **An empty file can remain after a failure.** If `create_database` or the backup step
   fails partway, the file stays, because nothing outside `transfer/delete.py` deletes
   files. The error message names the file. Known limitation.
4. **`list_recordings` loads every channel in one query.** Fine for thousands of
   recordings; not measured beyond that. Recorded as O16.
5. **Backup without the write lock in one case.** When the first migration step needs
   foreign keys switched off, the backup is taken before the lock. A comment in
   `migrations.py` explains why.
